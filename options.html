YOU MAY BE DRAFTED.

Configure the manuscript. The schedule remains classified.

STATUS UNCONFIGURED
Allowed reference URLs

During an active draft, DRAFTED will not drag you back if you switch to one of these pages. Use this for plot docs, notes, setting references, timelines, or research pages.

Active days

Choose the days DRAFTED may schedule ambushes. Manual test drafts still work on inactive days.

Excluded hours

DRAFTED will never activate inside these local-time ranges. Overnight ranges are allowed.

FIELD MANUAL / HOW TO USE
  1. Set the manuscript or writing page as Target URL.
  2. Add plot notes, research pages, or other safe tabs under Allowed reference URLs.
  3. Choose the weekdays and hours when ambushes are permitted, then set the daily count and keystroke quota.
  4. Turn on ARM DRAFTED and save. DRAFTED schedules hidden random ambushes for eligible times.
  5. When drafted, type until the HUD reaches zero. Drag the HUD if it covers something important.
  6. Use TEST DRAFT NOW whenever you want to verify your setup without consuming a scheduled ambush.
EMERGENCY EXIT

If you try to switch to a blocked tab, the YOU ARE STILL DRAFTED warning includes a tiny exit control at the upper-left. Use it to end only the current session; DRAFTED stays armed for later scheduled ambushes.
